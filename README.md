Hi, I'm **Moghees Ahmad**, a **Red Teamer & Penetration Tester** specializing in offensive security. My work focuses on **web, API, mobile application, cloud and Active Directory penetration testing**, vulnerability research, and helping development teams build more secure applications through practical remediation guidance.

I'm particularly interested in **Red Teaming**, **Active Directory security**, **Windows internals**, and **adversary simulation**. Most of my learning comes from hands-on practice through platforms like **Hack The Box**, **PortSwigger Web Security Academy**, **PwnedLabs**, and real-world penetration testing projects.
